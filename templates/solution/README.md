# __PROJECT__

Enterprise framework generated by **RyzCore** (`create-ryzcore`).

## Stack

- .NET 10 / ASP.NET Core Web API
- EF Core 10 + SQL Server
- Blazor WebAssembly
- .NET MAUI Blazor Hybrid
- MudBlazor
- JWT access/refresh token
- SignalR notifications
- Hangfire + ClosedXML/QuestPDF export
- Audit/log database terpisah
- Dynamic screen/report dan maker-checker approval

## Struktur

```
__PROJECT__/
├── __PROJECT__.sln
├── __PROJECT__.Domain/
├── __PROJECT__.Application/
├── __PROJECT__.Infrastructure/
├── __PROJECT__.Api/
├── __PROJECT__.Shared/
├── __PROJECT__.Web/
├── __PROJECT__.App/
└── database/
```

## Prasyarat

- .NET SDK 10
- SQL Server
- Workload MAUI (opsional, untuk project App)
- Node.js hanya diperlukan untuk generator, bukan untuk menjalankan aplikasi

## Konfigurasi

- `__PROJECT__.Api/appsettings.json` berisi konfigurasi non-rahasia.
- Connection string, JWT secret, dan password disimpan di `appsettings.Development.json` atau user-secrets (tidak di-commit).
- Database utama: `__DB_NAME__`
- Database audit/log: `__AUDIT_DB_NAME__`

## Menjalankan

```bash
dotnet restore
dotnet build
dotnet run --project __PROJECT__.Api
dotnet run --project __PROJECT__.Web
```

Untuk MAUI:

```bash
dotnet build __PROJECT__.App -f net10.0-windows10.0.19041.0
```

## Admin

Gunakan kredensial admin yang dicetak oleh installer. Segera ganti password setelah login pertama.
